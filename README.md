# Notes

- To update the CV pdf, place the new pdf in `assets/pdf/` and update the path in the `cv_pdf` field in `_pages/cv.md`.
- To update socials, go to `_data/socials.yml` and modify the relevant fields.
- Projects page has been removed by deleting the `projects.md` file in `_pages/`. To re-enable it, simply restore the file or copy it from the al-folio repository. `https://github.com/alshedivat/al-folio`
- Teaching page has been removed by deleting the `teaching.md` file in `_pages/`. To re-enable it, simply restore the file or copy it from the al-folio repository.
